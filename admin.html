1 Conexão com o GitHub

Crie um token só pra este repositório em github.com/settings/personal-access-tokens/new: escolha "Only select repositories" → selecione o repositório do portfólio → em "Repository permissions" marque Contents: Read and write. Nenhum outro acesso é necessário.
⚠️ Esse token dá permissão de editar o repositório. Ele fica salvo só no seu navegador (nunca é enviado pra mim nem sai do seu dispositivo, exceto direto para o GitHub). Não compartilhe esta página nem o token com ninguém, e não acesse este painel em computador público.
